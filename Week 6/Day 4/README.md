# Week 6 - Day 4

Node.js exercises arranged in learning order.

## Exercises

1. `01-commonjs-products` - CommonJS modules and product search
2. `02-es-modules-data` - ES modules and average age calculation
3. `03-commonjs-file-manager` - File reading and writing with `fs`
4. `04-todo-list` - Todo list class with ES modules
5. `05-lodash-math` - Custom module with lodash
6. `06-chalk-npm` - Styling terminal output with chalk
7. `07-file-explorer` - Copying files and reading directories
8. `08-path-file-info` - File metadata with `path` and `fs`
9. `09-axios` - Fetching post titles with axios
10. `10-date-fns` - Date calculations with date-fns
11. `11-faker-regex` - Faker data and regular expressions

## Installing Dependencies

Run the relevant command inside each exercise folder:

```bash
npm install
```

The dependency manifests are intentionally omitted from this submission after cleanup. Add the requested package with `npm install <package-name>` when running an exercise that needs one.
